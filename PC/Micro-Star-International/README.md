# Micro-Star-International (MSI) — Masaüstü Bilgisayar

MSI masaüstü bilgisayarın yapılandırma dosyaları ve araçları burada tutulur.

```text
Micro-Star-International/

```

Yeni yapılandırmalar için konu bazında alt klasör açın (örneğin `kde/`, `shell/`, `sistem/`) ve yukarıdaki listeye ekleyin.
